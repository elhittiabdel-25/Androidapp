1

Add the upload key to GitHub

Release builds are signed with a new upload key that never goes into the code. The four values are in the files I sent in the chat (reiman-upload-secrets.txt and reiman-upload.p12.base64).

  1. On GitHub, open the repository, then Settings → Secrets and variables → Actions → New repository secret.
  2. Add these four secrets, one at a time:
NameValue
UPLOAD_KEYSTORE_BASE64the whole content of reiman-upload.p12.base64
UPLOAD_KEYSTORE_PASSWORDthe password in reiman-upload-secrets.txt
UPLOAD_KEY_ALIASreiman-upload
UPLOAD_KEY_PASSWORDthe same password
  1. Open Actions → Build APK → Run workflow. After about 5 minutes, the new release must say “Signed with the upload key”. That .aab is the file for Google Play.
  2. Keep the key files in a safe place (a password manager or a private drive). If they're lost, Google can reset the upload key, but it takes a few days.

Run the closed test: 12 testers for 14 days

Tests fermés

Google requires new personal accounts to run a closed test with at least 12 testers who stay opted in for 14 days in a row before production. Someone who leaves and rejoins restarts their own count.

  1. Testing → Closed testing → Create track. Under Testers, create an email list with the Gmail addresses of 12 or more people (aim for 15 to keep a margin).
  2. Create release. When asked about app signing, keep Google-generated key (Play App Signing). Upload the .aab from the release that says “Signed with the upload key”.
  3. Release name: 1.0.0. Paste the release notes below.
  4. Review release → Start rollout. Once Google approves it (often within a day or two), copy the opt-in link and send it to your testers.

8

Publish, then update

Production

After approval: Production → Create release, add the same .aab (or a newer one), choose the countries, and roll out.

For every later update: I raise versionName (1.0.1, 1.1.0…) and push. The build produces a new .aab with a higher version code, and you upload it the same way. Testers and users then get the update from Google Play.
